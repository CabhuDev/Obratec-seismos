# Changelog

Todos los cambios relevantes del proyecto se documentan en este archivo.

## [0.1.0] - 2026-08-20

### Añadido

- API FastAPI para normalizar el feed público de terremotos del IGN.
- Caché por periodo y degradación a la última instantánea disponible.
- Filtros de periodo, magnitud y profundidad.
- Interfaz React premium con MapLibre, actividad reciente y estadísticas.
- Temas claro/oscuro y diseño responsive.
- Estados de carga, error y vacío.
- Tests unitarios y de integración para backend y frontend.
- Despliegue local mediante Docker Compose.
- Documentación de arquitectura, API, atribución y licencia.
